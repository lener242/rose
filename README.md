# Rose FamQ Discord Verification Bot

---

##  Основной функционал

*  **Авто-приветствие:** Отправка анкеты в ЛС при входе пользователя на сервер.
*  **Удобная форма:** Использование встроенных Modal-окон Discord для сбора данных (Ник, Имя, Static ID, Часы, Возраст).
*  **Авто-форматирование:** Автоматическая установка ника на сервере вида `Ник | Имя | Static ID`.
*  **Система модерации:** Заявки поступают в закрытый канал модераторов с интерактивными кнопками (Одобрить / Отклонить).
*  **Авто-роли:** Автоматическая выдача роли при одобрении заявки.
*  **Слэш-команды:** Возможность повторного вызова формы с помощью `/анкета`.
*  **Авто-чистка:** Очистка сторонних сообщений в канале анкет.

---

##  Технологический стек

* **Python** (версия 3.10 или выше)
* **discord.py** (версия 2.0+)
* **asyncio**

##  Инструкция по установке и запуску

### 1. Настройка Discord Developer Portal

1. Перейдите на [Discord Developer Portal](https://discord.com/developers/applications) и создайте новое приложение.
2. Перейдите во вкладку **Bot**:
   * Включите следующие **Privileged Gateway Intents**:
     * `PRESENCE INTENT` (по желанию)
     * `SERVER MEMBERS INTENT` — **Обязательно**
     * `MESSAGE CONTENT INTENT` — **Обязательно**
   * Скопируйте **Token** бота.

### 2. Подготовка окружения

1. Убедитесь, что у вас установлен Python 3.10+.
2. Склонируйте репозиторий или скачайте исходные файлы в папку проекта.
3. (Опционально) Создайте и активируйте виртуальное окружение:

   ```bash
   # Создание виртуального окружения
   python -m venv venv

   # Активация на Windows:
   venv\Scripts\activate

   # Активация на Linux/macOS:
   source venv/bin/activate
   ```

4. Установите необходимую библиотеку:

   ```bash
   pip install discord.py
   ```

---

### 3. Настройка конфигурации

Откройте файл бота `BotRoseDs.py` и проверьте следующие ID:

```python
GUILD_ID = 1458298216461369573                 # ID вашего сервера
APPLICATIONS_CHANNEL_ID = 1479584185524944927  # ID канала для заявок модераторам
APPROVED_ROLE_ID = 1477044728980836552         # ID роли верифицированного участника
MODERATOR_ROLE_IDS = [...]                     # Список ID ролей модераторов
ANKETA_CHANNEL_ID = 1480013460401160496        # ID канала анкет
```

---

### 4. Задание токена бота

Бот считывает токен из переменной окружения `DISCORD_BOT_TOKEN`.

#### 🔹 Вариант A: Через консоль / терминал

* **Windows (CMD):**
  ```cmd
  set DISCORD_BOT_TOKEN=ваш_токен_бота
  ```
* **Windows (PowerShell):**
  ```powershell
  $env:DISCORD_BOT_TOKEN="ваш_токен_бота"
  ```
* **Linux / macOS:**
  ```bash
  export DISCORD_BOT_TOKEN="ваш_токен_бота"
  ```

#### 🔹 Вариант Б: Использование `.env` файла

1. Установите библиотеку для работы с `.env`:
   ```bash
   pip install python-dotenv
   ```
2. Создайте файл `.env` в корневой папке проекта:
   ```env
   DISCORD_BOT_TOKEN=ваш_токен_бота
   ```
3. В начале `BotRoseDs.py` добавьте код:
   ```python
   from dotenv import load_dotenv
   load_dotenv()
   ```

---

### 5. Запуск бота

Выполните команду в терминале:

```bash
python BotRoseDs.py
```

При успешном запуске вы увидите сообщения:
```text
✅ Бот запущен как ИмяБота#0000 (ID: ...)
Слэш-команды синхронизированы.
```

##  Права бота на сервере

Для корректной работы убедитесь, что роль бота на сервере Discord:
1. Находится **выше** роли, которую он должен выдавать (`APPROVED_ROLE_ID`).
2. Имеет права:
   * `Управлять никнеймами` (Manage Nicknames)
   * `Управлять ролями` (Manage Roles)
   * `Управлять сообщениями` (Manage Messages)
   * `Отправлять сообщения` и `Встраивать ссылки` (Send Messages, Embed Links)
